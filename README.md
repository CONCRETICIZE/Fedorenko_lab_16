# Fedorenko_lab_16

Учебный мини-проект Степана Федоренко для лабораторной работы 16 по Git и GitHub.

## О проекте

Небольшой интерактивный журнал, который помогает на практике пройти основные этапы работы с репозиторием: коммиты, ветки, теги и публикацию изменений.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Состав

- `index.html` — структура страницы.
- `styles.css` — оформление.
- `app.js` — интерактивность.
